# Triage labels

The skills speak in terms of five triage roles. On our board each one is a tag on the card line, for example `[ready-for-human]`.

| Label in mattpocock/skills | Tag on our board card | Meaning |
| --- | --- | --- |
| `needs-triage` | `[needs-triage]` | Someone needs to look at this card |
| `needs-info` | `[needs-info]` | Waiting on someone for more information |
| `ready-for-agent` | `[ready-for-agent]` | Fully specified, a coding agent can do it |
| `ready-for-human` | `[ready-for-human]` | A person must do it (for example, graded tasks: decision 0003) |
| `wontfix` | `[wontfix]` | Will not be done; move the card to Dropped with a note |

When a skill says "apply the label", add the tag to the card line in `board.md`.
